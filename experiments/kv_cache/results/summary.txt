## Analysis

At seq_len=4096: No cache 35652.4ms/t vs KV cache 2302.8ms/t
KV cache provides 16x speedup at 1.5GB memory cost.

KV cache scales linearly with sequence length:
  seq_len=128   : 0.1GB
  seq_len=512   : 0.2GB
  seq_len=1024  : 0.4GB
  seq_len=4096  : 1.5GB
  seq_len=8192  : 3.1GB
  seq_len=16384 : 6.1GB
  seq_len=32768 : 12.2GB

At 32K context, KV cache alone consumes ~12GB.
This is why eviction strategies (LRU, H2O, Sliding Window) become necessary
for long-context serving on consumer GPUs.
